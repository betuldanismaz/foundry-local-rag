# Master Plan — Local RAG Q&A Assistant

## Overview

Build a fully offline document Q&A chatbot using Microsoft Foundry Local.
The app retrieves relevant chunks from a local document collection via
embedding similarity search (SQLite-backed), then feeds them to a local LLM
to generate grounded answers. Zero cloud calls, zero internet at inference.

This is a **teaching reference implementation** for a beginner CS summer
program. Every design choice prioritizes clarity and explainability.

## Key Constraints (apply to all steps)

- **No cloud calls** — everything through local Foundry endpoint
- **Same embedding model** for ingestion and query (mismatched = garbage)
- **Beginner-legible code** — explicit functions, no clever abstractions
- **Small/fast models** — phi-3.5-mini for chat, qwen3-embedding-0.6b for embeddings
- **SQLite brute-force** — no vector DB dependency, cosine sim in Python
- **Python 3.11+** required by the SDK

## Verification at Each Step
